# 开发文档

这里保存调研、设计、评测与迭代记录，不属于技能包。技能运行时只依赖 `skills/clear-communication/` 内的文件。

| 文档 | 用途 |
| --- | --- |
| [安装说明](installation.md) | 公开仓库链接安装、五种 agent 的目录、默认启用及验证 |
| [English installation](installation.en.md) | 英文安装与默认启用说明 |
| [指令中文对照](skill.zh-CN.md) | 英文运行入口的中文阅读版本 |
| [双语与发布资料](localization.md) | 仓库 description、语言分工、同步约定与发布状态 |
| [2026-10-25 审查](review-2026-10-25.md) | 规则歧义、流程成本和评测覆盖的检查与修正 |
| [已有材料与渐进改善](existing-material.md) | 输入文风、局部改写范围、已有术语和全面改造的设计依据 |
| [问题清单](problems.md) | 给写作缺陷编号，说明表现、后果、修正方向与来源 |
| [调研记录](research.md) | 记录检索方法、证据类型、原始链接和不能推出的结论 |
| [设计说明](design.md) | 解释规则为什么这样写，以及如何避免矫枉过正 |
| [评测方案](evaluation.md) | 保存可复用测试题、评分标准和跨模型比较方法 |
| [维护流程](maintenance.md) | 把真实反馈转成可验证的改进，控制规则膨胀 |
| [版本记录](changelog.md) | 记录变更、已完成验证与未验证事项 |

维护文档时使用稳定的问题编号和测试编号。规则可以调整，但不要悄悄删除旧结论的适用条件或把未完成的实验改写成既定成果。
